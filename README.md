
# Week 2 — Footprinting & Network Scanning Report

## Overview
This repository contains my Week 2 practical report from the Cybersecurity internship program at Networkwalks (Batch B083). It covers two core reconnaissance modules:

- **W2-PM1** — Footprinting a target domain using multiple Kali Linux tools
- **W2-PM5** — Local network discovery and scanning using Zenmap (Nmap GUI)

## What's Inside
- Domain footprinting against `networkwalks.com` (authorized target) using **WHOIS, WhatWeb, Nslookup, Curl, Wafw00f, and DNSRecon**
- Local network discovery on my own LAN using **Zenmap**, including live host identification, MAC addresses, and a network topology diagram
- A risk analysis table mapping each finding to a potential impact and risk level
- Security recommendations based on the observations
- Evidence screenshots for every tool/command run

## Tools Used
| Tool | Purpose |
|---|---|
| WHOIS | Domain registration lookup |
| WhatWeb | Web technology fingerprinting |
| Nslookup | DNS resolution |
| Curl | HTTP header inspection |
| Wafw00f | WAF detection |
| DNSRecon | DNS record enumeration |
| Zenmap (Nmap GUI) | Local network host discovery |
